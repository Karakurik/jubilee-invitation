# Приглашение на юбилей

Статический адаптивный сайт в татарском национальном стиле. Сервер и сборка не нужны.

## Быстрая настройка

Откройте `index.html` и замените демо-данные:

- `Гульнары` — имя юбиляра;
- `50 лет` — возраст;
- `17 октября 2026`, время, ресторан и адрес;
- текст программы и срок ответа.

В `script.js` замените:

```js
const TELEGRAM_USERNAME = 'your_username';
```

на username организатора без символа `@`.

## Персональная ссылка

Имя гостя передаётся query-параметром `name`:

```text
https://USERNAME.github.io/REPOSITORY/?name=Рамиль
```

Для пробелов и кириллицы безопасно использовать URL-кодирование:

```text
https://USERNAME.github.io/REPOSITORY/?name=Рамиль%20и%20Лилия
```

Также поддерживается параметр `guest`:

```text
https://USERNAME.github.io/REPOSITORY/?guest=Семья%20Сафины
```

Значение добавляется через `textContent`, поэтому HTML из query-параметра не исполняется.

## GitHub Pages

1. Создайте публичный репозиторий, например `jubilee-invitation`.
2. Загрузите в корень репозитория все файлы и папку `assets`.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
6. Ссылка будет вида `https://USERNAME.github.io/jubilee-invitation/`.

Если нужен короткий адрес, в **Settings → Pages → Custom domain** можно подключить свой домен и включить **Enforce HTTPS**.

## Альтернатива для РФ

Проект полностью статический, поэтому его можно теми же файлами разместить на любом российском хостинге статических сайтов или обычном веб-хостинге. Важное требование: `index.html` должен оставаться в корне сайта.

## Локальная проверка

Можно открыть `index.html` напрямую или запустить:

```bash
python3 -m http.server 8080
```

Затем перейти по адресу:

```text
http://localhost:8080/?name=Рамиль
```
